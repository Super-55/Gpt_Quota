# Quota Glass 0.4 设计与修复方案

本次保持现有五个统计页面、真实账户额度、5 小时重置倒计时和数据口径，解决窗口操作与视觉问题。

## 窗口交互

保留已可用的标题区域拖动。窗口四边和四角新增透明缩放热区，鼠标移入显示对应缩放指针，右下角显示小型缩放标记。按下时捕获指针，主进程记录原始窗口尺寸和鼠标 DIP 坐标；移动时基于原始坐标计算边界。对边保持固定，最小尺寸主窗口 760×540、紧凑面板 360×460，防止超出显示器工作区。

透明 Electron 窗口保持原生 `resizable:false`，通过受校验的 begin/update/end IPC 和 `setBounds` 实现手工缩放，避免直接启用原生 resize 导致透明失效。结束时提交最后位置，取消 RAF 并清零；所有手势操作串行，防止快速连续拖拽被上一轮结束请求打断。失焦、隐藏、最小化、关闭时清理手势。

窗口内容在玻璃容器内部滚动，文档本身固定为窗口大小。缩小后统计内容可滚动访问，表格需要时使用内部横向滚动，滚动条不游离于边框之外。

## 视觉

圆环保留真实剩余额度弧长。流光采用三层同心羽化：长光晕、较短中层和更短亮部，以不同模糊半径、低透明度柔化首尾，移除硬白胶囊边缘。圆环主体略细，并使用克制的粉色层次。

进度轨道改为低对比内嵌细轨道，填充使用柔和粉色渐变，穿梭高光降低亮度并加宽羽化范围。保持折线沿路径流光，以及未知／零值和减少动态效果的正确呈现。

## 置顶与背景

紧凑面板标题区域直接提供图钉按钮，显示当前置顶状态。切换写入原有 `alwaysOnTop` 设置，并实际调用原生置顶；设置面板保留对应选项，重启后沿用保存值。

新增 `backgroundEffect: transparent | frosted`，默认通透玻璃以兼容旧版。毛玻璃使用 Windows 11 22H2 及以上的原生 Acrylic，界面不使用 CSS 模糊冒充桌面模糊。设置保存后同时应用两个窗口，无需重开。切回透明时显式恢复透明背景色，以修复 Electron 39 将背景重置为白色的行为。不支持的系统选择毛玻璃时明确提示；加载已有设置时安全回退通透玻璃并显示说明。

“背景透明度”范围 0–90%，映射到已有的背景不透明度字段 100–10，兼容已保存值。只改变背景浓淡，文字不随之变透明。

## 验证

验证包含边界计算、低版本设置迁移、实际 OS 鼠标八方向拖拽与连续手势、标题拖动、原生置顶、设置持久化、最小尺寸下的内部滚动、原生桌面棋盘纹理模糊／还原、流光移动与减弱动态效果。真实桌面棋盘纹理对比区分原生模糊和单纯加深背景；单文件发行程序需实际启动并正常退出。

Electron 约束依据：[透明窗口限制](https://www.electronjs.org/docs/latest/tutorial/custom-window-styles)、[原生背景材质 API](https://www.electronjs.org/docs/latest/api/browser-window#winsetbackgroundmaterialmaterial-windows)。
