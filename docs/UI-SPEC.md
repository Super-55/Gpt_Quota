# 界面设计补充

本文件先于界面验收固化参考图的布局，不将截图未展示的内容冒充原产品。

## 视觉决策

选取玫瑰色磨砂玻璃为主要特征，保留参考图的密集数据视图。背景光只在窗口外围提供空间感，卡片内部保持足够不透明度保证阅读。无需照片壁纸和大标题。所有内容左对齐，数字对齐基线；热力图与趋势图占主要面积。

命名色板：墨紫 #21151e、玻璃 #382332、玫瑰 #f5a4cc、淡粉白 #fff2f8、灰紫 #c8abbc、琥珀 #eebd66。石墨主题仅改变表面色与背景，数据配色保持一致。

系统中文字体承担标签与正文，Segoe UI 数字使用 tabular-nums；32px指标、18px局部主值、13px正文、12px辅助说明。

## 相对通用仪表盘的取舍

参考图本来就是卡片仪表盘，因此保留卡片与粉色渐进图，不为追求不同而改成落地页、侧边栏后台或报纸排版。区别建立在窗口材质、紧凑布局和明确的数据来源上；去掉没有作用的装饰计数、宣传文案与循环动画。
