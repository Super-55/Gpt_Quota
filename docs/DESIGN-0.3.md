# Quota Glass 0.3 详细设计

## 功能与布局

主窗口导航依次为：今日任务、用量趋势、项目排行、Skill、模型用量。保持现有玻璃主题、透明窗口、折线与进度条光带。

取消紧凑面板的 Token 小目标和设置中的每日／每周目标输入。该位置改成“5 小时额度”，主窗口趋势页同步提供同一模块，内容依次为剩余百分比、已用百分比、剩余额度进度条、重置倒计时、绝对重置时间和来源／更新时间。旧设置中的目标值保留以兼容配置，不再影响界面。

5 小时模块只使用账户返回的 300 分钟窗口。账户未提供该窗口时显示未知，不从 Token 数估算，也不使用 7 天窗口冒充。重置时间没有返回时明确显示未知。到期后显示“等待额度更新”，保留最近记录，不自动假设额度已经恢复。

账户额度沿用独立的 5 秒定时读取。请求未完成时复用进行中的请求，避免并发堆积；请求失败保留最近结果并提供采集说明。倒计时由界面每秒更新，主窗口和紧凑面板共享账户结果。

## 模型用量

新增单独的模型用量页，包含今日、近 7 天、本地累计三个范围。每个范围显示总 Token、用量分组、模型识别比例，以及按 Token 降序排列的模型列表。列表包含模型名称、占比光带、总 Token、未缓存输入、缓存输入、输出和会话数。点击模型可查看精确分类、缓存率、会话数和最近记录。

统计输入包含缓存输入，因此总 Token = 未缓存输入 + 缓存输入 + 输出。时间按本机自然日计算，近 7 天包含今天。各模型五类 Token 之和必须与同范围总览相等。缺少模型名的事件单列“未知模型”，参与总量和占比分母。

读取每个 `turn_context.payload.model`，仅归属其后的 Token 增量。模型切换不改变之前事件，重复累计快照不新增用量。新一轮缺少模型字段时归未知，不能沿用上一轮模型。一个会话使用多个模型时，各模型分别计一次关联会话；模型会话数不能直接相加。

## 数据与兼容

`Dashboard` 新增 `quota5h: Quota | null` 与 `models: ModelUsage[]`。每个模型保存 `today`、`recent7`、`lifetime` 分类 Token，三个范围的会话数和最近活动时间。在线额度只更新额度字段，避免覆盖本地统计或清空最近一次扫描结果。

规范化缓存版本从 2 升为 3，旧缓存自动重扫原始日志，补充逐事件模型信息。缓存保留模型名、统计数和必要元数据，不保存消息正文、工具输出或认证信息。原始日志只读。

## 验证标准

单元测试覆盖模型切换、未知模型、增量扫描、重复计量、时间范围、分类对账、缓存迁移、精确 300 分钟筛选和演示数据一致性。桌面验证覆盖第五导航位置、范围切换、详情、目标控件移除、双窗口 5 小时模块、倒计时、未知状态、设置持久化及自动更新。真实窗口合成验证透明效果；独立高级模型验收记录在 `ACCEPTANCE-0.3.md`，最终发行 EXE 另做实际启动与正常退出检查。
